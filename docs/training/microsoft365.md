# Microsoft 365 Training Pathway

## Foundation

| Resource | Type | Duration |
|---|---|---|
| [Microsoft 365 Fundamentals — MS-900](https://learn.microsoft.com/en-us/training/paths/m365-fundamentals/) | Microsoft Learn | 4 hrs |
| [Microsoft Graph Fundamentals](https://learn.microsoft.com/en-us/training/paths/m365-msgraph-fundamentals/) | Microsoft Learn | 2 hrs |
| [Introduction to SharePoint](https://support.microsoft.com/en-us/sharepoint) | Microsoft Learn | 1 hr |
| [Introduction to Power Automate](https://learn.microsoft.com/en-us/training/paths/automate-process-using-flow/) | Microsoft Learn | 2 hrs |

**Outcome:** Understands the Microsoft 365 ecosystem and how services connect.

## Practitioner

| Resource | Type | Duration |
|---|---|---|
| [Build apps with Microsoft Graph](https://learn.microsoft.com/en-us/training/paths/m365-msgraph-associate/) | Microsoft Learn | 4 hrs |
| [SharePoint Framework (SPFx) — Getting Started](https://learn.microsoft.com/en-us/sharepoint/dev/spfx/set-up-your-developer-tenant) | Docs | 3 hrs |
| [Build Microsoft Teams Apps — Teams Toolkit](https://learn.microsoft.com/en-us/microsoftteams/platform/toolkit/teams-toolkit-fundamentals) | Docs | 3 hrs |
| [Microsoft Entra ID — Authentication Fundamentals](https://learn.microsoft.com/en-us/training/paths/identity-and-access/) | Microsoft Learn | 3 hrs |
| [Power Automate — Advanced Flows](https://learn.microsoft.com/en-us/training/paths/use-power-automate-business-process/) | Microsoft Learn | 3 hrs |

**Outcome:** Can develop Microsoft 365 integrations (SPFx, Graph API, Teams apps) following CoE standards.

## Expert

| Resource | Type | Duration |
|---|---|---|
| [Microsoft 365 Developer — MS-600 Learning Path](https://learn.microsoft.com/en-us/training/paths/m365-extend-fundamental/) | Microsoft Learn | 8 hrs |
| [Microsoft Purview — Information Protection](https://learn.microsoft.com/en-us/purview/information-protection) | Docs | 2 hrs |
| [Microsoft Entra — Conditional Access](https://learn.microsoft.com/en-us/entra/identity/conditional-access/overview) | Docs | 2 hrs |
| [Microsoft 365 Admin Centre — DLP Policies](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) | Docs | 1 hr |

**Outcome:** Can architect M365 solutions, manage governance, and contribute to CoE standards.
