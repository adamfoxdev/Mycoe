# Python Training Pathway

## Foundation

Suitable for engineers new to Python.

| Resource | Type | Duration |
|---|---|---|
| [The Python Tutorial — Official Docs](https://docs.python.org/3/tutorial/) | Docs | 4 hrs |
| [Python — Real Python Beginners Guide](https://realpython.com/python-first-steps/) | Tutorial | 2 hrs |
| [Type Hints Cheat Sheet](https://mypy.readthedocs.io/en/stable/cheat_sheet_py3.html) | Reference | 30 min |
| [pytest — Getting Started](https://docs.pytest.org/en/stable/getting-started.html) | Docs | 1 hr |
| [VS Code Python Setup](vscode.md#python-with-vs-code) | Guide | 30 min |

**Outcome:** Can write well-structured Python functions with type annotations, run pytest tests, and work comfortably in a virtual environment.

## Practitioner

Suitable for engineers building Azure Functions, automation scripts, or data engineering pipelines.

| Resource | Type | Duration |
|---|---|---|
| [Python Packaging with pyproject.toml](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/) | Docs | 1 hr |
| [Ruff Linter — Configuration](https://docs.astral.sh/ruff/configuration/) | Docs | 30 min |
| [mypy — Getting Started](https://mypy.readthedocs.io/en/stable/getting-started.html) | Docs | 1 hr |
| [Azure Functions Python Developer Guide](https://learn.microsoft.com/en-us/azure/azure-functions/functions-reference-python) | Docs | 2 hrs |
| [Azure Identity — DefaultAzureCredential](https://learn.microsoft.com/en-us/python/api/azure-identity/azure.identity.defaultazurecredential) | Docs | 30 min |
| [pytest — Fixtures and Parametrize](https://docs.pytest.org/en/stable/how-to/fixtures.html) | Docs | 1 hr |
| [unittest.mock — Mocking in Python](https://docs.python.org/3/library/unittest.mock.html) | Docs | 1 hr |

**Outcome:** Can build, test, and deploy Azure Functions; apply Ruff + mypy in CI; manage dependencies with `pyproject.toml`; mock external services in tests.

## Expert

For senior engineers and Python chapter leads.

| Resource | Type | Duration |
|---|---|---|
| [Fluent Python (2nd Edition)](https://www.oreilly.com/library/view/fluent-python-2nd/9781492056348/) | Book | 15 hrs |
| [Architecture Patterns with Python](https://www.oreilly.com/library/view/architecture-patterns-with/9781492052197/) | Book | 8 hrs |
| [Python Concurrency — asyncio Docs](https://docs.python.org/3/library/asyncio.html) | Docs | 2 hrs |
| [Semantic Kernel Python SDK](https://learn.microsoft.com/en-us/semantic-kernel/get-started/quick-start-guide?pivots=programming-language-python) | Docs | 2 hrs |
| [Great Expectations — Data Validation](https://docs.greatexpectations.io/) | Docs | 2 hrs |

**Outcome:** Can design Python services using domain-driven patterns, implement async pipelines, build Semantic Kernel agents in Python, and lead Python quality practices across the team.

## Recommended Certifications

- **Microsoft Certified: Azure Developer Associate (AZ-204)** — includes Python Azure Functions development
- **Microsoft Certified: Azure Data Engineer Associate (DP-203)** — covers Python-based data engineering with Azure
- **Microsoft Certified: Azure AI Engineer Associate (AI-102)** — covers Azure OpenAI and AI services via Python SDK
