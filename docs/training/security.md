# Security Training Pathway

## Foundation — All Engineers

Every engineer must complete this tier before working on any production system.

| Resource | Type | Duration |
|---|---|---|
| [OWASP Top 10 — 2021](https://owasp.org/Top10/) | Docs | 2 hrs |
| [Secure Coding Practices — Microsoft](https://learn.microsoft.com/en-us/training/modules/secure-coding-practices/) | Microsoft Learn | 1 hr |
| [Introduction to Identity and Access](https://learn.microsoft.com/en-us/training/paths/identity-and-access/) | Microsoft Learn | 2 hrs |
| [Microsoft Defender for Cloud — Overview](https://learn.microsoft.com/en-us/training/modules/protect-against-security-threats-azure/) | Microsoft Learn | 1 hr |
| [Secrets Management — Azure Key Vault](https://learn.microsoft.com/en-us/azure/key-vault/general/overview) | Docs | 30 min |

**Outcome:** Understands common vulnerabilities, identity principles, and secrets management.

## Practitioner — Security Champions

Complete this tier if you are your team's Security Champion, or aspire to be.

| Resource | Type | Duration |
|---|---|---|
| [Threat Modelling Fundamentals](https://learn.microsoft.com/en-us/training/paths/tm-threat-modeling-fundamentals/) | Microsoft Learn | 2 hrs |
| [STRIDE Threat Model — OWASP](https://owasp.org/www-community/Threat_Modeling_Process) | Docs | 1 hr |
| [GitHub Advanced Security — Secret Scanning](https://docs.github.com/en/code-security/secret-scanning/introduction/about-secret-scanning) | Docs | 30 min |
| [GitHub Advanced Security — Code Scanning (CodeQL)](https://docs.github.com/en/code-security/code-scanning/introduction-to-code-scanning/about-code-scanning-with-codeql) | Docs | 1 hr |
| [Dependency Review — GitHub Dependabot](https://docs.github.com/en/code-security/dependabot/dependabot-alerts/about-dependabot-alerts) | Docs | 30 min |
| [Zero Trust Architecture — Microsoft](https://learn.microsoft.com/en-us/security/zero-trust/zero-trust-overview) | Docs | 1 hr |
| [GDPR Developer Guide — CNIL](https://lincnil.github.io/GDPR-Developer-Guide/) | Docs | 2 hrs |

**Outcome:** Can lead threat modelling sessions, configure SAST/secret scanning, and champion secure development in the team.

## Expert — Security Engineers & Leads

| Resource | Type | Duration |
|---|---|---|
| [SC-200: Microsoft Security Operations Analyst Learning Path](https://learn.microsoft.com/en-us/training/paths/sc-200-mitigate-threats-using-microsoft-defender/) | Microsoft Learn | 10 hrs |
| [Microsoft Sentinel — Overview](https://learn.microsoft.com/en-us/azure/sentinel/overview) | Docs | 2 hrs |
| [Penetration Testing — OWASP Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Guide | 10 hrs |
| [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) | Framework | 3 hrs |
| [Microsoft Secure Development Lifecycle (SDL)](https://www.microsoft.com/en-us/securityengineering/sdl) | Framework | 2 hrs |

**Outcome:** Can lead security architecture decisions, conduct threat model reviews, and define security governance policies.

## Recommended Certifications

| Certification | Target Audience |
|---|---|
| SC-900: Microsoft Security Fundamentals | All engineers |
| SC-200: Microsoft Security Operations Analyst | Security Champions |
| AZ-500: Microsoft Azure Security Engineer | Platform / Security engineers |
| CISSP / CEH / OSCP | Senior security engineers |
