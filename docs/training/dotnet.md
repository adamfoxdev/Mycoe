| Resource | Type | Duration |
|---|---|---|
| [C# Fundamentals — Microsoft Learn](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/) | Docs | 3 hrs |
| [.NET 8 What's New](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-8/overview) | Docs | 1 hr |
| [ASP.NET Core — Create a Web API](https://learn.microsoft.com/en-us/aspnet/core/tutorials/first-web-api) | Tutorial | 2 hrs |
| [Entity Framework Core — Getting Started](https://learn.microsoft.com/en-us/ef/core/get-started/overview/first-app) | Tutorial | 2 hrs |
| [Dependency Injection in .NET](https://learn.microsoft.com/en-us/dotnet/core/extensions/dependency-injection) | Docs | 1 hr |

**Outcome:** Can create and run a basic ASP.NET Core Web API with EF Core.
