# Power BI Training Pathway

## Foundation

| Resource | Type | Duration |
|---|---|---|
| [Power BI Fundamentals — Microsoft Learn](https://learn.microsoft.com/en-us/training/paths/power-bi-consumer/) | Microsoft Learn | 3 hrs |
| [Power BI Desktop — Getting Started](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-getting-started) | Docs | 1 hr |
| [DAX in a Day — Microsoft (free PDF)](https://aka.ms/daxinadday) | eBook | 4 hrs |
| [Star Schema Design](https://learn.microsoft.com/en-us/power-bi/guidance/star-schema) | Docs | 1 hr |

**Outcome:** Can create a basic Power BI report from a simple data source.

## Practitioner

| Resource | Type | Duration |
|---|---|---|
| [Power BI Data Analyst — PL-300 Learning Path](https://learn.microsoft.com/en-us/training/paths/power-bi-data-analyst/) | Microsoft Learn | 10 hrs |
| [Row-Level Security in Power BI](https://learn.microsoft.com/en-us/power-bi/enterprise/service-admin-rls) | Docs | 1 hr |
| [Power BI Deployment Pipelines](https://learn.microsoft.com/en-us/power-bi/create-reports/deployment-pipelines-overview) | Docs | 1 hr |
| [Power BI Project (PBIP) format](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-overview) | Docs | 1 hr |
| [Tabular Editor 3 — Getting Started](https://docs.tabulareditor.com/) | Docs | 2 hrs |

**Outcome:** Can build production Power BI datasets and reports following Mycoe standards, including RLS and deployment pipelines.

## Expert

| Resource | Type | Duration |
|---|---|---|
| [Power BI Premium / Fabric — Overview](https://learn.microsoft.com/en-us/power-bi/enterprise/service-premium-what-is) | Docs | 2 hrs |
| [DirectQuery Best Practices](https://learn.microsoft.com/en-us/power-bi/connect-data/desktop-directquery-about) | Docs | 2 hrs |
| [ALM Toolkit — Dataset Comparison](https://alm-toolkit.com/) | Tool | 2 hrs |
| [DAX Optimization](https://www.sqlbi.com/articles/optimizing-dax/) | Articles (SQLBI) | 4 hrs |
| [Power BI Embedded](https://learn.microsoft.com/en-us/power-bi/developer/embedded/embedded-analytics-power-bi) | Docs | 2 hrs |

**Outcome:** Can lead data model design, optimise performance, embed reports in applications, and contribute to CoE standards.
