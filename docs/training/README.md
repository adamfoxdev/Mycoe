# Training Pathways

This section contains the learning and development pathways for each technology area in the Mycoe CoE.

## How to Use These Pathways

1. Identify your role and technology focus area
2. Work through the **Foundation** tier before advancing
3. Complete at least **Foundation + Practitioner** before working on a production project
4. **Expert** tier is optional but encouraged for senior engineers and chapter leads

All Microsoft Learn paths are free. Other resources are available via the organisation's learning platform (link to be inserted by L&D team).

## New Starter Checklist

Complete the following in your first two weeks:

- [ ] Read the [getting-started guide](../getting-started.md)
- [ ] Set up your local development environment (Node.js, .NET SDK, Azure CLI)
- [ ] Complete the Foundation tier for your primary technology
- [ ] Clone this CoE repository and explore the templates
- [ ] Pair with a team member to deploy a template to the dev environment
- [ ] Complete the Security Foundation training
- [ ] Complete the Copilot Foundation training
- [ ] If working on AI agent projects, complete the Agentic AI Foundation training
- [ ] Meet your team's Security Champion
