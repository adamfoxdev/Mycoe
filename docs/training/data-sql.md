# Data & SQL Training Pathway

## Foundation

Suitable for engineers new to SQL or data engineering.

| Resource | Type | Duration |
|---|---|---|
| [T-SQL Fundamentals — Microsoft Learn](https://learn.microsoft.com/en-us/sql/t-sql/language-reference) | Docs | 3 hrs |
| [Introduction to dbt](https://docs.getdbt.com/docs/introduction) | Docs | 1 hr |
| [Star Schema Explained](https://learn.microsoft.com/en-us/power-bi/guidance/star-schema) | Docs | 1 hr |
| [Azure SQL Documentation](https://learn.microsoft.com/en-us/azure/azure-sql/) | Docs | 2 hrs |

**Outcome:** Can write well-structured SQL queries, understand star schema design, and navigate Azure SQL.

## Practitioner

Suitable for engineers building and testing data pipelines and transformations.

| Resource | Type | Duration |
|---|---|---|
| [tSQLt — SQL Server Unit Testing](https://tsqlt.org/user-guide/) | Docs | 2 hrs |
| [dbt Testing Documentation](https://docs.getdbt.com/docs/build/data-tests) | Docs | 1 hr |
| [dbt-expectations package](https://github.com/calogica/dbt-expectations) | Docs | 1 hr |
| [Flyway — Database Migrations](https://documentation.red-gate.com/flyway) | Docs | 1 hr |
| [Azure Data Factory Testing Framework](https://learn.microsoft.com/en-us/azure/data-factory/concepts-pipeline-execution-triggers) | Docs | 2 hrs |
| [Testcontainers — SQL Server](https://dotnet.testcontainers.org/modules/mssql/) | Docs | 1 hr |

**Outcome:** Can write unit tests for stored procedures with tSQLt, add dbt data quality tests, and validate data pipelines.

## Expert

For senior data engineers and data chapter leads.

| Resource | Type | Duration |
|---|---|---|
| [The Data Warehouse Toolkit (Kimball)](https://www.kimballgroup.com/data-warehouse-business-intelligence-resources/kimball-techniques/) | Book | 10 hrs |
| [dbt Best Practices](https://docs.getdbt.com/best-practices) | Docs | 2 hrs |
| [Azure Synapse Analytics Architecture](https://learn.microsoft.com/en-us/azure/synapse-analytics/sql/overview-architecture) | Docs | 2 hrs |
| [Microsoft Fabric — End-to-End Tutorial](https://learn.microsoft.com/en-us/fabric/get-started/end-to-end-tutorials) | Tutorial | 4 hrs |
| [Great Expectations (Python data validation)](https://docs.greatexpectations.io/) | Docs | 2 hrs |

**Outcome:** Can design data platforms, lead data quality strategy, mentor others, and contribute to CoE standards.

## Recommended Certifications

- **Microsoft Certified: Azure Data Engineer Associate (DP-203)** — covers Azure SQL, Synapse Analytics, Data Factory, and Databricks
- **Microsoft Certified: Fabric Analytics Engineer Associate (DP-600)** — covers Microsoft Fabric end-to-end
