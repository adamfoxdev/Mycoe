# React Training Pathway

## Foundation

Suitable for engineers new to React or TypeScript.

| Resource | Type | Duration |
|---|---|---|
| [TypeScript for JavaScript Programmers](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html) | Docs | 30 min |
| [React Quick Start](https://react.dev/learn) | Interactive docs | 2 hrs |
| [React — Describing the UI](https://react.dev/learn/describing-the-ui) | Docs | 2 hrs |
| [React — Adding Interactivity](https://react.dev/learn/adding-interactivity) | Docs | 2 hrs |
| [React — Managing State](https://react.dev/learn/managing-state) | Docs | 2 hrs |
| [Vite Getting Started](https://vitejs.dev/guide/) | Docs | 30 min |

**Outcome:** Can read and write basic React components with TypeScript.

## Practitioner

Suitable for engineers who have React basics and are building production features.

| Resource | Type | Duration |
|---|---|---|
| [React Router v6 Tutorial](https://reactrouter.com/en/main/start/tutorial) | Tutorial | 2 hrs |
| [TanStack Query (React Query) — Quick Start](https://tanstack.com/query/latest/docs/framework/react/quick-start) | Docs | 1 hr |
| [Zustand Getting Started](https://zustand-demo.pmnd.rs/) | Docs | 1 hr |
| [Microsoft Authentication Library for React](https://learn.microsoft.com/en-us/azure/active-directory/develop/tutorial-v2-react) | Tutorial | 2 hrs |
| [Fluent UI v9 — Getting Started](https://react.fluentui.dev/?path=/docs/concepts-introduction--page) | Docs | 1 hr |
| [Testing Library — React](https://testing-library.com/docs/react-testing-library/intro/) | Docs | 2 hrs |
| [Vitest Getting Started](https://vitest.dev/guide/) | Docs | 1 hr |
| [Playwright — Getting Started](https://playwright.dev/docs/intro) | Docs | 1 hr |
| [Husky + lint-staged](https://typicode.github.io/husky/) | Docs | 30 min |

**Outcome:** Can build and test complete features using the Mycoe standard stack.

## Expert

For senior engineers and frontend chapter leads.

| Resource | Type | Duration |
|---|---|---|
| [TypeScript Deep Dive](https://basarat.gitbook.io/typescript/) | Book (free) | 8 hrs |
| [Advanced React Patterns](https://kentcdodds.com/workshops/advanced-react-patterns) | Workshop | 4 hrs |
| [Web Performance Fundamentals — web.dev](https://web.dev/learn/performance) | Course | 4 hrs |
| [Accessibility in React — MDN](https://developer.mozilla.org/en-US/docs/Learn/Tools_and_testing/Client-side_JavaScript_frameworks/React_accessibility) | Docs | 1 hr |
| [WCAG 2.2 Overview](https://www.w3.org/WAI/standards-guidelines/wcag/) | Docs | 2 hrs |

**Outcome:** Can lead architecture decisions for React apps, mentor others, and contribute to CoE standards.

## Recommended Certifications
