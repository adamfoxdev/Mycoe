# Azure Training Pathway

## Foundation

| Resource | Type | Duration |
|---|---|---|
| [Azure Fundamentals — AZ-900](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals-describe-azure-architecture-services/) | Microsoft Learn | 6 hrs |
| [Azure CLI Getting Started](https://learn.microsoft.com/en-us/cli/azure/get-started-with-azure-cli) | Docs | 1 hr |
| [Introduction to Bicep](https://learn.microsoft.com/en-us/training/paths/fundamentals-bicep/) | Microsoft Learn | 3 hrs |
| [Azure DevOps — Get Started](https://learn.microsoft.com/en-us/azure/devops/get-started/?view=azure-devops) | Docs | 2 hrs |

**Outcome:** Understands core Azure services and can read/modify Bicep templates.

## Practitioner

| Resource | Type | Duration |
|---|---|---|
| [Azure Developer Associate — AZ-204 Learning Path](https://learn.microsoft.com/en-us/training/paths/create-azure-app-service-web-apps/) | Microsoft Learn | 10 hrs |
| [Intermediate Bicep](https://learn.microsoft.com/en-us/training/paths/intermediate-bicep/) | Microsoft Learn | 4 hrs |
| [Azure Key Vault — Developer Guide](https://learn.microsoft.com/en-us/azure/key-vault/general/developers-guide) | Docs | 2 hrs |
| [Managed Identities for Azure Resources](https://learn.microsoft.com/en-us/azure/active-directory/managed-identities-azure-resources/overview) | Docs | 1 hr |
| [Azure Monitor — Getting Started](https://learn.microsoft.com/en-us/azure/azure-monitor/overview) | Docs | 2 hrs |
| [Azure DevOps YAML Pipelines](https://learn.microsoft.com/en-us/azure/devops/pipelines/yaml-schema/) | Docs | 2 hrs |
| [Cloud Adoption Framework — Naming Conventions](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ready/azure-best-practices/resource-naming) | Docs | 1 hr |

**Outcome:** Can create and manage Azure infrastructure using Bicep and deploy via Azure DevOps.

## Expert

| Resource | Type | Duration |
|---|---|---|
| [Azure Solutions Architect — AZ-305 Learning Path](https://learn.microsoft.com/en-us/training/paths/design-identity-governance-monitor-solutions/) | Microsoft Learn | 15 hrs |
| [Advanced Bicep](https://learn.microsoft.com/en-us/training/paths/advanced-bicep/) | Microsoft Learn | 4 hrs |
| [Azure Well-Architected Framework](https://learn.microsoft.com/en-us/azure/well-architected/) | Docs | 4 hrs |
| [Microsoft Defender for Cloud](https://learn.microsoft.com/en-us/azure/defender-for-cloud/overview-page) | Docs | 2 hrs |

**Outcome:** Can architect Azure solutions, lead platform decisions, and contribute to CoE standards.

## Recommended Certifications

| Certification | Target Audience |
|---|---|
| AZ-900: Azure Fundamentals | All engineers |
| AZ-204: Azure Developer Associate | Backend / Full-stack engineers |
| AZ-400: Azure DevOps Engineer Expert | Platform / DevOps engineers |
| AZ-305: Azure Solutions Architect Expert | Senior engineers and architects |
