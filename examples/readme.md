# Starter Solution Examples

Ready-to-use example projects for each technology area. Clone or copy the folder that matches your project type and follow the README inside to get started quickly.

## Available Examples

| Example | Technology | What It Demonstrates |
|---|---|---|
| [dotnet-api/](dotnet-api/) | ASP.NET Core 8 | Full CRUD REST API with EF Core, Serilog, Swagger, xUnit tests |
| [react-vite-app/](react-vite-app/) | React 18 + Vite + TypeScript | SPA with MSAL auth, TanStack Query, Fluent UI, Vitest tests |
| [copilot/](copilot/) | GitHub Copilot | `.github/copilot-instructions.md` for a full-stack project |
| [powerbi/](powerbi/) | Power BI / DAX | Sales dashboard measures (time intelligence, rankings, RLS) |

## How to Use

1. Pick the example closest to your project type.
2. Read the `README.md` inside that folder for prerequisites and quick-start instructions.
3. Adapt the code to your domain — replace placeholder names (e.g., `Products`, `Tasks`) with your own entity names.
4. Reference the corresponding docs in `docs/standards/` and copy any reusable scaffolding from `templates/`.

## Relationship to Templates

| Folder | Purpose |
|---|---|
| `templates/` | Generic, fill-in-the-blanks scaffolding (configuration files, empty patterns) |
| `examples/` | Concrete, domain-specific implementations of those templates (this folder) |

Start with an example to get something running, then refine using the templates for project-specific configuration.
